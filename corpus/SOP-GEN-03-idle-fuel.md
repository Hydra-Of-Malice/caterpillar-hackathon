# SOP-GEN-03 Idle and fuel practice

## 1. Purpose and scope

### 1.1 Purpose
This procedure explains when engine idling is expected, when to shut the engine down, and how to reduce fuel use without slowing the work.

## 2. Idle time

### 2.1 What counts as idle
Idle is time with the engine running while the machine is not working. Some idle is expected, for example waiting for a truck, warm-up and cool-down. Idle without a reason is unexplained idle.

### 2.2 Waiting for a truck
When you are waiting for a truck, mark the task state as "waiting for truck" in CAT Sentinel. Idle while waiting for a truck is explained idle and is not flagged.

### 2.3 Shutting down during long waits
Shut the engine down if you expect to wait longer than the site idle limit. The SAMPLE site idle limit is 5 minutes. Complete the safe-park steps before you shut down.

### 2.4 Automatic idle features
Use the machine's automatic engine idle and idle shutdown features where they are fitted, as described in the OMM.

## 3. Warm-up and cool-down

### 3.1 Warm-up
Warm the machine up as described in the OMM before working at full load. Start with light work and low engine speed until the engine and hydraulic oil reach operating temperature.

### 3.2 Cool-down
After heavy work, let the engine idle for a few minutes before you shut it down so that engine temperatures can settle. The SAMPLE site practice is 3 to 5 minutes of cool-down, or as the OMM specifies.

### 3.3 Warm-up and cool-down are explained idle
Idle for warm-up or cool-down is explained idle and is reported separately from unexplained idle.

## 4. Fuel-efficient operation

### 4.1 Power mode and engine speed
Use the lowest power mode and engine speed that do the job at a steady pace.

### 4.2 Short swings
Set up the dig face and truck position so that the swing is short. A shorter swing saves fuel and time on every cycle.

### 4.3 Fuel used while idling
A 20-tonne-class excavator uses fuel even at idle. The SAMPLE planning figure for this site is 3 litres per hour at idle; check the machine's own fuel data for real values.
